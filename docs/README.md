# Documentation

Three documents, in the order most people want them.

| Document | Read it if | Currency |
|---|---|---|
| [ANALYSIS.md](ANALYSIS.md) | You want to know **why this exists** and what it deliberately isn't — the survey of prior art it came out of, and the constraints that fell out of that survey. | Written before implementation, August 2026. Kept unedited. §7 (out of scope) still governs; the third-party tool claims will age. |
| [DECISIONS.md](DECISIONS.md) | You are **changing the code** and want to know why something is the way it is before changing it back. | Current. Add an entry when you make a call someone will otherwise re-litigate. |

The [README](../README.md) covers usage, the code tour, and how to add an
importer. [CONTRIBUTING.md](../CONTRIBUTING.md) is the review bar for pull
requests.
